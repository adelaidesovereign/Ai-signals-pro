## CONTENT PRODUCTION SHORTCUTS

### Batch Filming Hack:
Film all 3 daily videos in ONE session (under 1 hour):
1. Change top/accessories between videos for variety
2. Use trending sounds (save 10 each week)
3. Keep a "hook bank" — never start from scratch

### The 3-Second Rule:
Every video must hook in the first 3 seconds:
- Start mid-sentence
- Open with a bold claim
- Use pattern interrupts (unexpected visuals or sounds)

### Repurposing Engine:
```
1 TikTok Live → 5 short-form clips → 3 IG stories 
→ 1 email newsletter → 2 tweet threads
```
One live session = 10+ pieces of content.
